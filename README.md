# Kinetik.Struct // Experimental Editorial Portfolio

An experimental editorial portfolio and creative engineering showcase blending Civil Engineering, Information Technology, and Brutalist Graphic Design. Built with Svelte, Three.js, GSAP, and WebGL.

## Overview
- **Disciplinary Synthesis**: Editorial lookbook and high-contrast typography pairing architectural infrastructure documentation with digital systems.
- **Tectonic Weaving Thread**: Continuous responsive SVG structural thread connecting sections with live scroll telemetry.
- **Real-Time WebGL Engine**: Hardware-accelerated wireframe telemetry field and interactive 3D CAD sandbox.
- **Dynamic Structural Archive**: Live FEM bridge deflection solver, seismic waveform HUD, variable typeface specimen explorer, and Navier-Stokes watershed CFD simulation.
- **Performance Optimized**: Sub-second initial paint, 100% WebP image pipeline, GPU-accelerated calligraphy signature loader, and zero layout thrashing.

## Tech Stack
- [Svelte 4](https://svelte.dev/)
- [Vite](https://vitejs.dev/)
- [Three.js](https://threejs.org/)
- [GSAP](https://greensock.com/gsap/)
- [Lenis Smooth Scroll](https://github.com/darkroomengineering/lenis)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
